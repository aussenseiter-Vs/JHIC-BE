# Program Keahlian SMK JHIC

SMK JHIC membuka tiga program keahlian.

## Pengembangan Perangkat Lunak dan Gim (PPLG)

Sebagai programmer, kalian akan belajar dasar-dasar pemrograman, membuat
aplikasi web, aplikasi mobile, dan pengembangan gim.

## Akuntansi

Sebagai calon akuntan, kalian akan belajar siklus akuntansi, penyusunan
laporan keuangan, perpajakan, dan menggunakan perangkat lunak akuntansi.

## Perhotelan

Sebagai calon pekerja di industri perhotelan, kalian akan belajar pelayanan
front office, housekeeping, pelayanan makanan dan minuman, serta keselamatan
tamu.

Siswa yang lulus dari ketiga program ini dapat melanjutkan studi ke jenjang
pendidikan tinggi atau langsung bekerja di bidangnya masing-masing.
